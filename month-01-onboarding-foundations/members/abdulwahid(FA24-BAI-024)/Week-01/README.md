# NumPy & Pandas Tasks

Solutions to the NumPy and Pandas assignments (10 assignments × 2 tasks each) for the GDG On Campus AI/ML Team, COMSATS University Islamabad (Attock Campus).

## Files

| Notebook | Description |
|---|---|
| `numpy_tasks.ipynb` | Array creation, indexing, operations, statistics, broadcasting, linear algebra, structured and masked arrays |
| `pandas_tasks.ipynb` | DataFrames, cleaning, aggregation, merging, time series, MultiIndex, pivot tables, text data |

## Setup

```bash
pip install numpy pandas jupyter
jupyter notebook
```

Open either notebook and run all cells. Both use `np.random.seed(42)`, so random outputs are reproducible.

## Requirements

- Python 3.9+
- NumPy
- Pandas
